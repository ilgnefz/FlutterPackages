## 0.2.1

* README 加了**国际化**整节：`TimePickerLabels` 六个成员、locale 三件套怎么配、
  为什么「什么都没配」反而是英文、怎么加第三门语言（日文完整示例）、不在
  labels 里的 `label` / `hint`、常见坑。
* 底部「取消 / 确定」改成**正常字重**（原来 `w600`），与表盘的间隔 4 → 8。
* 上午 / 下午改成**整段滑块平移动画**（200ms）：一块主色底在两段之间滑动，文字
  颜色跟着渐变；两段固定等宽，切语言时布局不跳。
* 测试 33 条：新增 locale 三件套 / 只配 locale 回退英文 / 自定义 labels /
  `resolve` / 滑块平移 / 按钮字重，以及原有 27 条。

## 0.2.0

表盘改成**双圈**：外圈分、内圈时，两圈同时可用；「上午 / 下午」常驻。

* 表盘（`TimeDial`）：外圈 `00 05 … 55` 改分、内圈 `12 1 … 11` 改时。点哪圈改
  哪圈，不用先切「在调小时还是分钟」；正在调的那圈是实心点 + 指针杆，另一圈是
  空心点，两个值都看得见。按住拖动时**落点跨圈就跟着切圈**（外圈→内圈改时、
  再回去改分），跨圈时通知面板把左边高亮也切过去。分界取在两圈数字中间
  （0.67R）。
* 「上午 / 下午」两段常驻在时间下面（以前只有 12 小时制才有）。内圈是 12 小时
  表盘，24 小时制也靠它区分 `03` / `15`。
* 左边两个数字框**不再显示「时 / 分」小字**（`TimePickerStyle.fieldCaptionStyle`
  删除）；`TimePickerLabels.hour` / `minute` 保留，改成读屏用的语义标签。
* 上午 / 下午改成紧凑分段控件（选中段是主色底 + 白字）。
* 表盘数字与选中圆点的避让改成按字号算：数字不会再被圆点啃掉一半。
* 内圈标签样式（`dialInnerLabelStyle`）现在指「小时」数字，默认 10 号；外圈
  （`dialLabelStyle`）默认 11.5 号。
* **不兼容**：`TimeDial` 去掉 `use24HourFormat` 参数（内圈永远是 12 小时盘，
  上下午由面板决定）；`TimeDialMode` 现在只表示「哪一圈在编辑」。
* 测试 27 条：双圈互不影响、外圈任意分钟、拖动跨圈切 mode、24 小时制上下午补 12、
  12 小时制表盘只给 `1..12`，以及原有的输入 / 弹窗 / 样式 / 光标用例。

## 0.1.0

第一个可用版本：紧凑时间选择器（面板 / 输入框 / 定位弹窗）。

* `TimePickerPanel`：左边是**可直接编辑**的时间（小时、分钟各一个两位数字框，
  敲 `0~23` / `0~59`，回车或失焦自动补零、夹到合法范围），右边是圆形表盘。
  点哪一段，表盘就切到哪一项——没有 Material 那个「切换输入方式」的按钮。
* 表盘（`TimeDial`）：调小时外圈 `12 1 … 11`，24 小时制多一圈内圈
  `00 13 … 23`（按半径判内外圈）；调分钟外圈 `00 05 … 55`，指针可停在任意分钟。
  支持点一下、也支持拖着走。
* 12 小时制自动出现「上午 / 下午」两段；切换制式**不会**把已经选好的时间冲掉。
* `TimePickerField`：带标题 / 时钟图标的输入框，点开面板，确定后回填。
* `showTimePicker` / `showCompactTimePicker`：按 `placement` 弹在锚点上下左右，
  放不下自动翻面并夹回视口；外部点击 / Esc 关闭返回 null。
* `TimePickerStyle`：宽度、圆角、投影、表盘尺寸、内外圈字号、时间字号、数字框
  尺寸、高亮底色、按钮字号、`mouseCursor` 全在里面。
* `TimePickerLabels`：上午 / 下午、「时 / 分」、取消 / 确定，`zh` / `en` /
  `of(context)`，按 locale 自动选。
* 测试 23 条：格式、默认尺寸、直接输入 / 补零 / 越界夹取、表盘点选（含 24 小时
  内圈与 12 小时制）、确定 / 取消、样式覆盖、光标、制式切换保留值、弹窗定位与
  返回值、输入框回填。
